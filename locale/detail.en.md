1. Open **Plugins → Installed plugins** and select **Check for updates** (检查更新).
2. When a compatible version is available, select **Update** (更新) on that plugin’s row. If it stalls, select **Stop update** (停止更新).
3. Daily checks notify you of updates. Turn them off at the bottom of the list (自动检查更新).

Supports plugins installed from npm or public GitHub repositories. For local installations, update from the original source.

[Read the full English guide on GitHub](https://github.com/jabingu/dsh-plugin-updater/blob/main/README.en.md)
