## 本轮发现并处理的问题

1. `npm view package@* <fields>` 在实际查询中只返回一个 manifest。改为先读版本索引，再查询精确版本，避免遗漏较早的兼容版本。
2. DSH 左侧入口实际位于 `nav` 中；改用注册表返回的本地化标签匹配唯一导航按钮，不依赖 `aside` 容器。
3. 行内 flex 样式可能覆盖 HTML 的 `hidden` 默认样式。为本插件自己的隐藏节点增加局部规则，并增加计算样式与浏览器可见性检查。
